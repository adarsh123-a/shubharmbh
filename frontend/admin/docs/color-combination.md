# Admin Dashboard - Color Combination Guide

## 🛡️ Role Identity & Theme
The Admin role handles operational management—monitoring properties, customer enquiries, and the Relationship Manager (RM) team. The color scheme features warm bronze and amber accents paired with clear operational status badges.

---

## 🌈 Core Palette

| Element | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Role Accent Badge** | Amber Shield Pill | `#FEF3C7` (Bg) / `#B45309` (Icon/Text) | Header role indicator |
| **Hero Banner Card** | Royal Navy Gradient | `linear-gradient(135deg, #0F172A, #1E3A8A)` | Admin dashboard welcome banner |
| **Main Background** | Clean White-Slate | `#F8FAFC` | Screen canvas background |
| **Card Surface** | White Card | `#FFFFFF` | Metric tiles, graphs, enquiry cards |
| **Borders** | Light Border | `#E2E8F0` | Card borders & input outlines |
| **Heading Text** | Slate Dark | `#0F172A` | Section titles, customer names |
| **Subtext / Meta** | Slate Muted | `#64748B` | Timestamps, property descriptions |
