# Agent Dashboard - Color Combination Guide

## 🧑‍💼 Role Identity & Theme
The Agent Dashboard caters to real estate brokers and property representatives. Its color palette prioritizes property listing visibility, lead responsiveness, and active booking statuses.

---

## 🌈 Core Palette

| Element | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Role Accent Badge** | Indigo Agent Pill | `#EDE9FE` (Bg) / `#6D28D9` (Icon/Text) | Header role indicator |
| **Hero Banner Card** | Royal Navy Gradient | `linear-gradient(135deg, #0F172A, #1E3A8A)` | Agent dashboard welcome banner |
| **Main Background** | Clean White-Slate | `#F8FAFC` | App screen background |
| **Card Surface** | White Surface | `#FFFFFF` | Property cards, enquiry cards, stats |
| **Borders** | Subtle Gray | `#E2E8F0` | Property card outlines & dividers |
| **Heading Text** | Slate Dark | `#0F172A` | Property titles, customer names |
| **Price Text** | Shubharambh Navy | `#0F172A` | Price highlight (e.g. ₹ 85 Lakh) |

| Status | Background | Text Color | Usage |
| :--- | :--- | :--- | :--- |
