# Customer Portal & App - Color Combination Guide

## 👥 Role Identity & Theme
The Customer Portal focuses on discovery, aspirational luxury real estate browsing, trust, and effortless enquiry tracking. The visual style features modern card layouts, category highlights, and vibrant property accents.

---

## 🌈 Core Palette

| Element | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Role Accent Badge** | Customer Amber Pill | `#FEF3C7` (Bg) / `#B45309` (Icon/Text) | Header role indicator |
| **Hero Card Background** | Midnight Luxury Indigo | `linear-gradient(135deg, #0F172A, #1E293B)` | "Find Your Dream Property" hero card |
| **Hero Title / Accent** | Pure White & Warm Gold | `#FFFFFF` / `#F59E0B` | Catchy header typography |
| **Main Background** | Crisp Slate White | `#F8FAFC` | App screen background |
| **Card Surface** | White Elevation | `#FFFFFF` | Property cards, search container, enquiry rows |
| **Search Bar Border** | Soft Gray | `#E2E8F0` | Search bar outline & shadow |
| **Price Highlighting** | Royal Blue Accent | `#2563EB` | Property price (e.g., ₹ 85 Lakh) |
| **Wishlist Heart** | Rose Red | `#EF4444` (Filled) / `#94A3B8` (Outline) | Bookmark/favorite property icon |
