# RM (Relationship Manager) Dashboard - Color Combination Guide

## 🧑‍🤝‍🧑 Role Identity & Theme
The Relationship Manager portal is designed for high-efficiency daily tasks—site visits, customer calls, and enquiry tracking. It uses warm energetic amber tones combined with clear actionable task badges.

---

## 🌈 Core Palette

| Element | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Role Accent Badge** | RM Amber Pill | `#FEF3C7` (Bg) / `#C2410C` (Icon/Text) | Header role indicator |
| **Hero Banner Card** | Royal Navy Gradient | `linear-gradient(135deg, #0F172A, #1E3A8A)` | RM Dashboard welcome banner |
| **Main Background** | Clean White-Slate | `#F8FAFC` | Screen canvas background |
| **Card Surface** | Card White | `#FFFFFF` | Metric tiles, task lists, customer cards |
| **Borders** | Subtle Gray | `#E2E8F0` | Task dividers and input borders |
| **Primary Text** | Slate Dark | `#0F172A` | Customer names, task titles |
| **Secondary Text** | Slate Muted | `#64748B` | Scheduled timings, addresses |
