# Super Admin Dashboard - Color Combination Guide

## 👑 Role Identity & Theme
Super Admin represents maximum authority and enterprise-level governance. The color palette combines deep midnight navy with royal gold accents and a multi-dimensional metric status palette.

---

## 🌈 Core Palette

| Element | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Role Accent Badge** | Midnight Gold Crown | `#1E293B` (Bg) / `#F59E0B` (Icon) | Role identification pill on top header |
| **Hero Banner Card** | Royal Navy Gradient | `linear-gradient(135deg, #0F172A, #1E3A8A)` | Welcome & organizational metrics banner |
| **Main Background** | Slate Off-White | `#F8FAFC` | App screen background |
| **Card Background** | Pure White | `#FFFFFF` | Metric tiles, chart wrappers, list cards |
| **Dividers & Borders** | Soft Gray Border | `#F1F5F9` / `#E2E8F0` | Card borders and horizontal rules |
| **Primary Text** | Deep Slate | `#0F172A` | Primary card values, section headers |
| **Secondary Text** | Slate Muted | `#64748B` | Subtitles, timestamps, field descriptions |
