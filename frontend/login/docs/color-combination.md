# Login & Authentication - Color Combination Guide

## 🎨 Brand & Theme Overview
The authentication portal uses Shubharambh Realty's signature luxury palette—combining deep royal navy, rich gold accents, and clean white glassmorphism for a trustworthy and premium first impression.

---

## 🌈 Core Palette

| Role / Element | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Brand** | Royal Navy | `#0F172A` | Header text, primary headings, dark surfaces |
| **Brand Accent** | Shubharambh Gold | `#D97706` | Primary action buttons, active highlights, logos |
| **Accent Gradient** | Warm Gold Gradient | `linear-gradient(135deg, #B45309, #F59E0B)` | Submit / Login buttons, promo badges |
| **Background** | Clean Off-White | `#F8FAFC` | Main screen background |
| **Card Surface** | Pure White / Glass | `#FFFFFF` | Form containers, auth modal boxes |
| **Borders** | Subtle Gray | `#E2E8F0` | Input borders, card dividers |
| **Input Focus** | Gold Glow | `#F59E0B` (Border) / `rgba(245, 158, 11, 0.15)` | Focused input outline & shadow |

When users select their role on the login screen:

| Role | Badge Background | Text / Icon Color |

| **Admin** | `#FEF3C7` (Light Amber) | `#B45309` (Amber Shield) |
| **RM** | `#FFEDD5` (Soft Peach) | `#C2410C` (Rust Orange) |
| **Agent** | `#EDE9FE` (Soft Violet) | `#7C3AED` (Deep Purple) |

## ⚡ Feedback & Status Colors

| State | Background | Text / Icon | Purpose |
| :--- | :--- | :--- | :--- |
| **Success** | `#DCFCE7` | `#16A34A` | Successful login, OTP verified |
| **Error** | `#FEE2E2` | `#DC2626` | Invalid credentials, OTP expired |
| **Warning** | `#FEF3C7` | `#D97706` | Session expiring, incomplete profile |
| **Info** | `#DBEAFE` | `#2563EB` | Resend OTP timer, helpful tips |
